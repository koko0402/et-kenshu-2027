第4回 C言語（2）関数・構造体

関数と構造体を使って、走行体のデータをまとめて扱う練習をします。ドリルの問題5〜8をやります。

用意するもの：第3回のドリルの続き

説明

関数に分ける理由

モータに出力を渡す前には、必ず -100〜100 に収めます。こういう「毎回同じことをする処理」は関数にしておくと、直すときに1か所で済みます。2026年のプログラムでは、モータに出力を渡す処理は src/device/motor.c の motor_set_power() 1か所にまとめていました。

構造体

関係のある値をまとめて1つにしたものが構造体です。

typedef struct {
    float x_mm;
    float y_mm;
    float heading_rad;
} Pose;

Pose p = {0.0f, 0.0f, 0.0f};
p.x_mm += 100.0f;

構造体を関数に渡すときは、ふつうはポインタで渡します。ポインタで受け取ったときは . ではなく -> で中身を使います。

void odometry_update(Pose *pose, float dl_mm, float dr_mm)
{
    pose->x_mm += ...;     /* (*pose).x_mm と同じ */
}

odometry_update(&p, 10.0f, 10.0f);

前の値を覚えておく

センサの値をなめらかにする処理や PID のように、前の値を使う計算はよく出てきます。その「覚えておく値」を構造体に入れておいて、関数に渡すたびに更新します。問題8の移動平均がその練習です。

オドメトリ

左右の車輪がどれだけ回ったかから、自分の位置と向きを計算することをオドメトリといいます。左右が同じだけ進めばまっすぐ、逆向きに同じだけ進めばその場で回ります。

進んだ距離 ds = (左 + 右) / 2
向きの変化 dh = (右 − 左) / 左右の車輪の間隔

第7回のシミュレータでも、ガレージへ向かうときに進んだ距離や回った角度を使います。

演習

演習4-1　モータの出力を範囲に収める（問題5）

ヒント 条件を見る順番が大事。先に ±100 の外かを見て、そのあと「0ではないけど小さすぎる」かを見る。なぜ小さい出力をわざわざ大きくするのかは、第6回のシミュレータで出力を5にしてみると分かる（車輪が回らない）。

演習4-2　キャリブレーション（問題6）

黒と白の明るさから、線の縁の明るさ（目標輝度）を出します。

ヒント `normalize` は、掛け算を先にしないと割り算で0になる。

演習4-3　自分の位置を計算する（問題7）

ヒント テストの「その場で左へ約90度」の110mmは、半径70mmの円の4分の1の長さ。`cosf`・`sinf` は `` に入っている。

演習4-4　移動平均（問題8）

ヒント `index = (index + 1) % 5` で 0, 1, 2, 3, 4, 0, ... と回して、古い値に上書きしていく。最初のうちは5個そろっていないので、たまっている数で割る。
