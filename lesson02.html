第2回 パソコンの準備

プログラムを書いて動かすための道具を、自分のPCに入れます。その前に、ファイルとフォルダの話を少しします。ここがあいまいだと、このあと何度もつまずくからです。

用意するもの：自分のPC（Windows）、GitHub のアカウント（無ければこの回で作る）

説明

ファイルとフォルダ

PCの中のものは、全部「ファイル」です。写真も、Wordの文書も、これから書くプログラムもファイルです。ファイルは「フォルダ」の中に入っていて、フォルダの中にさらにフォルダを入れられます。

ファイルの名前の最後の . から後ろを「拡張子」といって、何のファイルかを表しています。hello.c ならC言語のプログラム、README.md なら Markdown という書き方の文章、index.html ならWebページです。

Windows は最初、拡張子を隠しています。プログラムを書くときは見えないと困るので、表示するようにします（手順の1）。

プログラムを書いて動かすまで

C言語のプログラムは、人が読める文字で書いた「ソース」を、コンパイラという道具でPCが動かせる形（実行ファイル）に変えてから動かします。この変換を「コンパイル」といいます。ETロボコンでは gcc というコンパイラを使います。

ソースを書くのにはエディタを使います。メモ帳でも書けますが、VS Code を使うと、色分けしてくれたり、間違いを教えてくれたりします。

コンパイラを動かしたり、作ったプログラムを動かしたりするのは「ターミナル」という、文字でコマンドを打つ画面です。Windows では Git Bash というターミナルを使います。ターミナルは次の回でじっくり練習します。

入れるもの

この回で入れるのは次の3つです。

  • Git for Windows … Git（プログラムの変更を記録する道具、第4回）と、ターミナルの Git Bash が入る
  • VS Code … エディタ
  • WinLibs … gcc（Cのコンパイラ）と mingw32-make（make の Windows 版、第9回）が入る

Python も使いますが、第18回で入れます。

手順

拡張子を表示する

  1. エクスプローラー（フォルダの黄色いアイコン）を開く
  2. 上の「表示」→「表示」→「ファイル名拡張子」にチェックを入れる

道具を入れる

  1. スタートメニューで「PowerShell」と打って開き、次の3行を1行ずつ打って Enter を押す（終わるまで数分かかる。途中で「はい」を聞かれたら「はい」）

    winget install Git.Git
winget install Microsoft.VisualStudioCode
winget install BrechtSanders.WinLibs.POSIX.UCRT

  2. PowerShell を閉じる。PCを一度再起動しておくと確実

VS Code の準備

  1. VS Code を開く
  2. 左のアイコンの並びにある「拡張機能」（四角が4つのアイコン）を押し、「Japanese Language Pack」を探して入れる。右下に出る「再起動」を押すと日本語になる
  3. 同じように「C/C++」（Microsoft のもの）と「Draw.io Integration」も入れておく
  4. 上のメニューの「ターミナル」→「新しいターミナル」を押す。下に黒っぽい画面が出る
  5. その右上の + の横の ∨ を押して「Git Bash」を選ぶ。行の最後が $ になっていれば Git Bash

  6. 次のように打って、3つとも版の番号が出ることを確かめる（$ は打たない。打つのはその後ろだけ）

    $ gcc --version
$ mingw32-make --version
$ git --version

    command not found と出るものがあったら、VS Code を閉じて開き直してから、もう一度打つ。それでもだめなら先輩に言う

プロジェクトを取ってくる

  1. GitHub のアカウントが無ければ、https://github.com で作る
  2. 先輩に GitHub のアカウント名を伝えて、チームのリポジトリ（プログラムや資料の置き場所）に招待してもらう。メールで来る招待を承認して、リポジトリのURLも教えてもらう

  3. Git Bash で、デスクトップに取ってくる（<リポジトリのURL> の所に教えてもらったURLを入れる）

    $ cd ~/Desktop
$ git clone <リポジトリのURL> ETrobo

    初めてのときは GitHub にログインする画面が出るので、ブラウザでログインする

  4. VS Code の「ファイル」→「フォルダーを開く」で、デスクトップの ETrobo を開く。左に src、docs などのフォルダが並べば成功

VS Code の使い方を少しだけ

左のファイルの一覧でファイルを押すと、真ん中に中身が出ます。Ctrl + S で保存です。保存していないファイルは、上のタブに白い丸が付きます。

Ctrl + P でファイルの名前を打つと、そのファイルを探して開けます。Ctrl + Shift + F で、全部のファイルの中から文字を探せます。.md のファイルは、開いて Ctrl + Shift + V を押すと見やすく表示されます。

演習

演習2-1　中を見て回る

VS Code の左の一覧で、docs/後輩育成/新人研修2027/ドリル を開いて、q01_distance.c を開いてください。最初のコメントに何が書いてありますか。

演習2-2　探す

Ctrl + Shift + F で LAPゲート を探してください。いくつのファイルに出てきましたか。いちばん上に出てきたファイルを開いてみてください。

演習2-3　拡張子

docs/後輩育成 の中にある、拡張子が .pdf、.mp4、.md のファイルを1つずつ見つけて、それぞれ何のファイルか想像してください。

次回までに

VS Code で Git Bash を出せるようにしておいてください。次回はずっとターミナルを使います。
