付録 コマンド早見表

印刷して手元に置いておくためのものです。PCは VS Code の Git Bash で ETrobo のフォルダから、ラズパイは ssh pi@etrobo.local で入って cd ~/etrobo してから打ちます。

ターミナル（第3回）

コマンド すること
pwd 今いる場所
ls / ls -l 中身の一覧 / 大きさと日時も
cd 場所 / cd .. 移動 / 1つ上へ
cat / less 中身を見る（less は q で終わる）
head -n 10 / tail -n 5 最初の10行 / 最後の5行
tail -f ファイル 増えていく行を見続ける（Ctrl + C で終わる）
grep 文字 ファイル 文字を含む行（-n 行番号、-c 数、-v 含まない行）
mkdir -p 名前 フォルダを作る
cp / mv / rm 写す / 動かす・名前を変える / 消す（戻せない）
Tab / ↑ / Ctrl + C 名前を補う / 前のコマンド / 止める

Git（第4回）

コマンド すること
git status 変えたファイルの一覧
git diff 何をどう変えたか
git restore ファイル 最後に記録した状態に戻す（今の変更は消える）
git add / git commit -m "説明" 記録に入れる / 記録する
git pull / git push 取ってくる / 送る

C言語（第5〜9回）

コマンド すること
gcc -Wall -o hello hello.c hello.c から hello を作る（-lm は数学の関数を使うとき）
./hello 作ったものを動かす
mingw32-make Makefile のとおりに作る（ラズパイでは make）
sh check.sh 1 ドリルの問題1を採点（sh check.sh で全部）

練習用シミュレータ（第11・12回）

コマンド すること
mingw32-make my_robot.c で作って走らせる。result.html で再生
./entry_sim --seed 3 --quiet 機体の癖を変えて、結果だけ
mingw32-make answer 答えの例で走らせる

走行体（第16・17回）

場所 コマンド すること
PC ssh pi@etrobo.local ラズパイに入る（exit で出る）
PC sh scripts/deploy.sh pi@etrobo.local 送ってビルド。「== 完了。」が出れば成功
PC scp pi@etrobo.local:etrobo/logs/run_*.log . ログを持ってくる
ラズパイ ls /dev/ttyACM* /dev/video* ハブとカメラが見えているか
ラズパイ make camera SHOT=1 カメラの向きを確かめる
ラズパイ make check 点検（車輪を浮かせて）
ラズパイ make start OPT="--line-trace-only --speed 20" 走らせる（打つ前にハブの電源を入れ直す）
ラズパイ pgrep -af "[e]trobo /dev\|[v]ision_server" 前の走りが残っていないか
ラズパイ sync → sudo poweroff 片付け。ランプが消えてから抜く

本物のプログラムをPCで（第19回）

コマンド すること
sh scripts/local_test.sh 単体テスト（全部 OK になってから送る）
mingw32-make build/rally_sim シミュレータを作る
python scripts/sim_view.py --bottles --seed 3 1回走らせて logs/sim_view_bottles.html で再生

困ったとき

出たもの すること
No such file or directory 名前の打ち間違いか、場所が違う。pwd と ls
command not found つづりを確かめる。入っていなければ入れる
何も出ずに止まった Ctrl + C
getdevice time out ハブの電源を切って5秒待って入れ直す
SPIKE version mismatched! make pi SPIKE_VERSION=0.1.1 のように台に合わせる
ssh がつながらない 同じ Wi-Fi か。番号が変わっていないか
走行体がずれて危ない ハブの電源を切る
