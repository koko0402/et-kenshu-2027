大会

言葉 意味
エントリー・ベーシック・アプライド ETロボコンのクラス。うちは2026年にアプライドに出た
HackSPi dachs アプライドクラスの走行体。SPIKE Prime ＋ Raspberry Pi 4 ＋ USBカメラ
リザルトポイント 1回の走行の点数。走行ポイント＋課題ポイント
走行ポイント LAPゲートまでの速さで決まる点
チェックポイント 前半の途中にあるゲート。通ると点が入る
LAPゲート 前半のゴール
難所 後半の課題。2026年のアプライドは ETラリー・ET相撲・ボトルデリバリー
ガレージ 最後に止まる場所
キャリブレーション 走る前に、黒と白の明るさをセンサに覚えさせること
モデル審査 提出した設計図（モデル）を審査員が読んで付ける評価
講評 大会のあとに届く、審査員からのコメント
規約 大会のルールを書いた文書。毎年変わる

走行体

言葉 意味
ハブ SPIKE Prime のハブ。モータとセンサがつながる。ラズパイの言うとおりに動く
ラズパイ Raspberry Pi。小さな Linux のパソコン。走行体のプログラムが動く
RasPike-ART ラズパイとハブを組み合わせた、ETロボコン公式の環境
カラーセンサ 床の明るさや色を見るセンサ
反射光 カラーセンサが返す明るさ。0〜100
超音波センサ 正面の物までの距離を測るセンサ
ジャイロ 何度回ったかが分かるセンサ。ハブに入っている
フォースセンサ 押しボタン。スタートに使う
ストール モータが回そうとしているのに回らない状態
静止摩擦 小さい出力では車輪が回り出さないこと

制御

言葉 意味
ライントレース 床の線をたどって走ること
縁（エッジ） 線の端。白と黒の境目。ここをたどる
目標輝度 黒と白の真ん中の明るさ。縁の上ならこの明るさになる
ずれ（偏差） 目標と今の値の差
PID制御 ずれの大きさ（P）、たまり方（I）、変わる速さ（D）から、どれだけ曲がるかを決める方法
ゲイン KP・KI・KD のこと。どれだけ強く効かせるか
オドメトリ 車輪の回転から、進んだ距離や自分の位置を計算すること
状態機械 今の状態と、何が起きたら次の状態に移るかで動きを決める作り方
seed（種） シミュレータで機体の癖を変えるための番号。同じ番号なら同じ走りになる

プログラム

言葉 意味
ソース 人が書いたプログラムの文字のファイル（.c など）
コンパイル ソースを、PCが動かせる形（実行ファイル）に変えること
コンパイラ コンパイルする道具。gcc
ビルド コンパイルなどをして、動かせる形を作ること全体
警告（warning） 動くけれど怪しい書き方を教えてくれるもの。チームでは0にする
変数 値に名前を付けて覚えておくもの
関数 決まった仕事に名前を付けてまとめたもの
構造体 関係のある値をまとめて1つにしたもの
ポインタ 値そのものではなく、値がある場所
ヘッダ .h のファイル。関数の宣言や構造体の形を書く
make / Makefile どのファイルをどう作るかを書いておいて、一言で作る道具とその手順書
単体テスト 部品ごとに「こう入れたらこうなるはず」を確かめるプログラム
シミュレータ 実機の代わりに、仮想のコースで走らせるプログラム
ログ 走行体が走りながら書いた記録

道具

言葉 意味
ターミナル 文字でコマンドを打つ画面。Windows では Git Bash を使う
パス ファイルやフォルダの場所の書き方（docs/後輩育成 など）
ssh ネットワーク越しに別のコンピュータに入って操作する方法
IPアドレス ネットワーク上の住所
Git ファイルの変更を記録する道具
GitHub Git の記録をインターネット上に置く場所
コミット Git の1回分の記録
ブランチ Git の記録の枝分かれ
リポジトリ Git で管理しているプログラムや資料の置き場所
draw.io モデル図を描く道具
UML モデル図の決まった書き方
