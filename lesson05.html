第5回 はじめてのC言語

C言語で、いちばん小さいプログラムを書いて、コンパイルして動かします。走行体のプログラムも、これを大きくしたものです。

用意するもの：第2回で準備したPC

説明

いちばん小さいプログラム

#include <stdio.h>

int main(void)
{
    printf("こんにちは ETロボコン\n");
    return 0;
}

1行ずつ見ていきます。

#include <stdio.h> は、画面に文字を出す printf などを使うための準備です。おまじないだと思って構いません。

int main(void) から } までが、プログラムの本体です。プログラムは必ず main から始まります。

printf("...\n"); は画面に文字を出します。\n は改行です。C では、命令の最後に ; を付けます。

return 0; は「正常に終わった」と知らせます。

コンパイルして動かす

C は、書いたらコンパイルしてから動かします。

$ gcc -Wall -o hello hello.c
$ ./hello
こんにちは ETロボコン

gcc がコンパイラで、hello.c から hello（Windows では hello.exe）という実行ファイルを作ります。-Wall は怪しい書き方を全部「警告」として教えてくれる指定です。-o hello は、できる実行ファイルの名前です。./hello で、今いるフォルダの hello を動かします。

警告（warning）が出ても実行ファイルはできますが、警告はたいてい本当の間違いです。チームでは警告が1つも出なくなるまで直すことにしています。

変数と printf

値に名前を付けて覚えておくのが変数です。

int speed = 70;          /* 整数 */
float offset = -0.25f;   /* 小数。最後に f を付ける */

printf("速さ %d、ずれ %.2f\n", speed, offset);   /* 速さ 70、ずれ -0.25 */

printf の中の %d には整数が、%f には小数が入ります。%.2f は小数2桁です。

関数

決まった仕事に名前を付けてまとめたものが関数です。

float run_point(float lap_time_sec)
{
    float point = 35.0f - lap_time_sec;
    if (point < 0.0f) {
        point = 0.0f;
    }
    return point;
}

float run_point(float lap_time_sec) は「小数を1つ受け取って、小数を1つ返す、run_point という関数」という意味です。return で結果を返します。if (...) { ... } は、条件が成り立つときだけ中を実行します。

演習

演習5-1　エラーを読む

手順4で出たエラーをよく読んでください。次のように出たはずです（文字の数は書いた内容で少し違います）。

hello.c:5:37: error: expected ';' before 'return'

5:37 は何を表していますか。expected ';' before 'return' はどういう意味でしょう。

答え `5:37` は5行目の37文字目。「return の前に ; があるはず」という意味で、5行目の最後に ; が無いことを教えてくれている。今の gcc は抜けた場所の行を指してくれるが、括弧の閉じ忘れなどでは、おかしいと気づいた所（もっと下の行）を指すこともある。指された行におかしな所が無ければ、上の行を見る。エラーがたくさん出ても、直すのはいちばん上の1つ目だけでいいことが多い。
