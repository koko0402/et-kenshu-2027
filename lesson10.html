第10回 ライントレースのしくみ

走行体は、床の黒い線の縁をカラーセンサで見ながら走ります。これをライントレースといいます。この回は、文字だけで動く小さなシミュレータで、PID制御を自分で書いて、値を変えると走りがどう変わるかを体験します。

用意するもの：第8回のドリル（問題9の PID）

説明

線の縁をたどる

カラーセンサは、床の明るさ（反射光）を0〜100の数字で返します。白い床なら80くらい、黒い線の上なら10くらいです。

線の真ん中をたどろうとすると、センサが線の右にずれても左にずれても「白」になってしまい、どちらに戻ればいいか分かりません。そこで、線の縁（白と黒の境目）をたどります。境目の上ならちょうど白と黒の間の明るさ（目標輝度）になります。暗ければ線のほうに寄りすぎ、明るければ線から離れすぎ、と、どちらにずれたかが分かります。

目標輝度は、走る前に黒と白の明るさを実際に測って、その真ん中にします。これがキャリブレーションです（ドリル問題6）。

曲がる量を決める

0.1秒ごとに次をくり返します。

反射光を読む
  ↓
ずれ e = 目標輝度 − 反射光
  ↓
曲がる量 = KP × e ＋ KI × （e の合計） ＋ KD × （e の変化）
  ↓
左の出力 = 速さ ＋ 曲がる量、右の出力 = 速さ − 曲がる量

左右の車輪の速さを変えると曲がります。左を速くすれば右に、右を速くすれば左に曲がります。

遅れ

モータに指示を出しても、車輪がすぐにその速さになるわけではありません。センサを読んでから車輪が反応するまでに、少し遅れがあります。この遅れがあるので、強く曲がりすぎると行き過ぎて、戻ろうとしてまた行き過ぎて、揺れがだんだん大きくなります。D はこの揺れを抑えるために入れます。

手順

  1. 練習のフォルダに入って、コンパイルして動かす

    $ cd ~/Desktop/ETrobo/docs/後輩育成/練習/04_ライントレース
$ gcc -Wall -o line_sim line_sim.c -lm
$ ./line_sim

    コースは「まっすぐ → ゆるい左カーブ → まっすぐ → きつい右カーブ → まっすぐ」（全長2.8m）です。0.5秒ごとに、線の縁からのずれが * の位置で出ます。| が縁で、60mm以上ずれると「線を見失いました」で止まります

  2. line_sim.c の decide_steering() を書く。最初は P だけ（return pid->kp * error;）

  3. ./line_sim 0.6 0 0 のように、KP・KI・KD の順に値を付けて走らせる

演習

演習10-1　P だけで走らせる

P だけで書いて、./line_sim 0.6 0 0 で走らせてください。どこで線を見失いますか。

答え 10.4秒ごろ、2つ目のきつい右カーブで見失う。

演習10-2　PID を全部書く

decide_steering() のコメントの手順どおりに、I と D も入れてください。./line_sim（KP 0.6、KI 0、KD 0.3。2026年の本物と同じ値）でゴールできれば完成です。

ゴールしました（14.6秒）。
いちばん大きいずれ 3.6mm、平均のずれ 1.4mm

演習10-3　値を変えて表にする

次の組み合わせで走らせて、結果を表に書いてください。

KP KI KD ゴールしたか いちばん大きいずれ 気づいたこと
0.6 0 0.3
0.6 0 0
0.15 0 0
1.2 0 0
0.6 0 1.5
0.6 0.3 0.3

KP を小さくしすぎると、なぜ見失うのでしょう。大きくしすぎると、なぜ見失うのでしょう。D を入れると何が良くなりましたか。

答え 0.6・0・0.3 はゴール（最大3.6mm）。0.6・0・0 は10.4秒で見失う。0.15・0・0 は4.5秒で見失う（最初のカーブで曲がり切れない）。1.2・0・0 は4.1秒で見失う（右へ左へ揺れが大きくなる）。0.6・0・1.5 はゴールするが少し遅い（最大8.3mm、17.0秒。D が強すぎると曲がるのを嫌がる）。0.6・0.3・0.3 はゴールするが、カーブのあと戻りすぎる（最大8.7mm）。2026年のチームは I を0にしていた。 KP が小さいと曲がる力が足りず、カーブで外にふくらむ。大きいと、遅れの間に曲がりすぎ、戻すときもまた曲がりすぎて、揺れが大きくなる。D はずれが急に大きくなったとき（カーブの入口）に早めに曲げ始め、戻りすぎるときにはブレーキになるので、揺れが収まる。

演習10-4　条件を変える

line_sim.c の上のほうの #define を変えて試してください。速さ（BASE_SPEED を40から60に）、遅れ（DELAY_STEPS を1から2に）、センサが見る範囲（EDGE_MM を4から8に）。それぞれ、同じ PID の値で走れますか。

速さや遅れが変わると、ちょうどいい PID の値も変わります。本物のプログラムで、区間ごとに速さと PID の値を切り替えている（src/section/）のはこのためです。

次回までに

自分の decide_steering() を残しておいてください。次回、別のシミュレータでもう一度使います。
