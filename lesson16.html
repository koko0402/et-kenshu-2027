第16回 ラズパイをつなぐ（実習）

ここからは実機です。走行体に載っている Raspberry Pi 4（ラズパイ）は、手のひらくらいの大きさの Linux のパソコンです。何も入っていないラズパイを、PCから操作して走行体のプログラムが動くところまで持っていきます。必ず先輩と一緒にやってください。

用意するもの：Raspberry Pi 4、microSDカード（32GBくらい）とカードリーダー、モバイルバッテリーとUSB-Cケーブル、ラズパイとハブをつなぐUSBケーブル、SPIKE Prime ハブ、USBカメラ

説明

何が何につながっているか

  PC  ── Wi-Fi（ssh）──  Raspberry Pi 4  ── USBケーブル ──  SPIKE Prime ハブ
                            │       │                         （モータ・センサ）
                        USBカメラ  モバイルバッテリー

プログラムを書くのはPCです。ラズパイには画面もキーボードもつながず、PCから ssh で入って文字で操作します。

走行体のプログラムはラズパイの上で動きます。カメラの画像から線を探して、どのくらい曲がるかを決めて、ハブに「左を40、右を60で回して」と送ります。ハブには公式の raspike というファームウェアが入っていて、言われたとおりにモータを回し、センサの値を返すだけです。考えるのはラズパイで、ハブは手足です。この組み合わせを RasPike-ART と呼んでいて、ETロボコンの公式の環境です。

ラズパイの中

ラズパイの中は Linux です。ターミナルのコマンドは、第3回で練習したものがそのまま使えます。ユーザー名は pi、走行体のプログラムは ~/etrobo（/home/pi/etrobo）に置きます。

Linux では、機械もファイルのように見えます。ハブは /dev/ttyACM0、カメラは /dev/video0 という名前で見えていて、ここに書いたり読んだりするとハブやカメラとやり取りできます（実際の読み書きは、公式のライブラリがやってくれます）。

ラズパイでよく使うコマンドは、自分の番号（IPアドレス）を出す hostname -I、SDカードの空きを見る df -h、管理者の権限で動かす sudo、ソフトを入れる sudo apt install 名前、書き込みを今すぐ終わらせる sync、電源を切る準備をする sudo poweroff です。

ケーブルと電源

ラズパイとハブをつなぐUSBケーブルは、データ通信ができるものでないといけません。充電専用のケーブルだとハブが見えないのですが、見た目では区別できません。通信できたケーブルにはテープで印を付けておいてください。

ラズパイの電源はモバイルバッテリーです。容量が足りないとラズパイごと落ちることがあります（2026年10月に2回ありました）。

2026年に何度も踏んだこと

ハブは、走らせ直すたびに電源を完全に切って入れ直します。ハブのメニューを選び直すだけだと前の状態のまま固まっていて、getdevice time out と出て動きません。

ラズパイの電源を、動いている途中でいきなり抜くと、書いたばかりのファイルが壊れることがあります。ビルドした直後に電源を切って、Makefile やプログラムが0バイトになったことがあります。必ず sudo poweroff で止めてから抜きます。

手順

SDカードを作る

  1. PCに Raspberry Pi Imager を入れる（公式サイトから）
  2. デバイスは Raspberry Pi 4、OSは Raspberry Pi OS (64-bit)、ストレージは差したSDカードを選ぶ
  3. 「設定を編集する」で次を入れる。ここを飛ばすと、画面もキーボードも無いラズパイには入れなくなる
    • ホスト名：etrobo（2台目は etrobo2 のように台ごとに変える）
    • ユーザー名：pi、パスワードはチームで決めているもの
    • Wi-Fi：部室のWi-Fiの名前とパスワード、国は JP
    • SSH：有効にする
  4. 書き込む（5〜10分）。終わったらSDをラズパイに差す
  5. どの台に何を入れたかを、docs/走行用/ のメモに1行残す

起動して入る

  1. バッテリーをつなぐ。最初の起動は2〜3分かかるので待つ

  2. PCの Git Bash で呼んでみる

    $ ping -c 3 etrobo.local
64 bytes from 192.168.1.23: icmp_seq=1 ttl=64 time=5.12 ms

  3. ssh で入る。最初の1回だけ yes を聞かれる。パスワードは打っても画面に何も出ないが、そのまま打って Enter

    $ ssh pi@etrobo.local
pi@etrobo:~ $

    行の頭が pi@etrobo になっている間は、ラズパイの中で打っている。PCに戻るときは exit

  4. 公開鍵を登録して、次からパスワード無しで入れるようにする（PC側で1回だけ）

    $ ls ~/.ssh/id_ed25519.pub || ssh-keygen -t ed25519
$ cat ~/.ssh/id_ed25519.pub | ssh pi@etrobo.local "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"

プログラムを送ってビルドする

  1. PCの Git Bash で、ETrobo のフォルダから送る。資料以外のプログラム一式がラズパイの ~/etrobo に送られ、足りない部品が入って、ラズパイの上でビルドされる（初回は10分以上かかる）

    $ cd ~/Desktop/ETrobo
$ sh scripts/deploy.sh pi@etrobo.local

ハブとカメラをつなぐ

  1. ハブの電源を入れて、ハブの画面で raspike を選ぶ（∞ の表示になる）
  2. 通信できるUSBケーブルでラズパイとつなぎ、ラズパイの中で ls /dev/ttyACM* と打つ。/dev/ttyACM0 が出ればハブが見えている
  3. カメラをつないで ls /dev/video* と打つ。USBカメラは /dev/video0（video10 より後ろはラズパイの中の部品）

  4. 1枚撮る

    pi@etrobo:~ $ cd ~/etrobo
pi@etrobo:~/etrobo $ make camera SHOT=1

  5. PCに持ってきて見る（PCの Git Bash で scp pi@etrobo.local:etrobo/logs/camera_aim.png .）

動かしてみる

  1. 車輪を浮かせてから点検する

    pi@etrobo:~/etrobo $ make check

  2. 遅いライントレースだけ走らせる。左右の車輪が両方とも前に回れば大丈夫。止めるときは Ctrl + C、止まらなければハブの電源を切る

    pi@etrobo:~/etrobo $ make start OPT="--line-trace-only --speed 20"

片付ける

  1. sync してから sudo poweroff。緑のランプが消えてからバッテリーを抜く

うまくいかないとき

ping で could not find host と出るときは、名前で探せないネットワークです。ルーターの管理画面か arp -a で、ラズパイの番号（IPアドレス）を探して、ssh pi@192.168.x.x のように番号で入ります。3分待っても返事が無いなら、Wi-Fiの名前かパスワードの間違いが多いので、SDを作り直します。

ping は返るのに ssh だけつながらないことがあります。2026年9月に学校のWi-Fiで起きて、Wi-Fi側で端末どうしの通信を止めていたのが原因でした。スマホのテザリングか、自分たちのルーターを使います。

SDを作り直したあとに ssh すると、REMOTE HOST IDENTIFICATION HAS CHANGED! と出ます。作り直したのが確かなら、ssh-keygen -R etrobo.local で古い記録を消せば入れます。

/dev/ttyACM0 が出ないときは、まずケーブルを疑います。起動してすぐ SPIKE version mismatched! と出て止まるときは、ハブのファームウェアの版とプログラムが合っていないので、make pi SPIKE_VERSION=0.1.1 のようにその台に合わせてビルドし直します。

電源を急に切ってしまったら、次に起動したとき find ~/etrobo -size 0 で空のファイルを探して、あれば deploy.sh で送り直します。

演習

演習16-1　1台セットアップする

手順を最初から最後まで、先輩と一緒に通してやってください。カメラの画像をPCで開けて、make check が通れば終わりです。

演習16-2　自分のPCから入る

自分のPCに公開鍵を登録して、パスワード無しで ssh pi@etrobo.local で入れるようにしてください。

演習16-3　書き足す

途中で詰まったことを、この授業の「うまくいかないとき」に書き足してください（授業/16_ラズパイをつなぐ.md）。来年の新人が同じ所で詰まらずに済みます。
