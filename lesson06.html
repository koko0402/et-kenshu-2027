第6回 C言語 変数・条件・繰り返し

前の回で書いた小さなプログラムの続きです。走行体で使う計算を題材に、変数・条件・繰り返しを練習します。この回からドリルを使って、問題1〜4をやります。

用意するもの：第5回で使ったPC

説明

ドリルのしくみ

ドリル/ の中に q01_distance.c から q12_logline.c まで12個のファイルがあります。ファイルの先頭のコメントが問題文で、/* ここに書く */ の所を書き換えて関数を完成させます。関数の名前や引数は変えないでください。

書いたら sh check.sh 1 のように問題の番号を付けて採点します。

$ sh check.sh 1
問題1  距離から車輪の角度へ（変数と計算）
  × 314.159mm → 360度  → 0.000 になった（正しくは 360.000）
  ○ 0mm → 0度
  ...
  1 / 4

× の行には、何を入れたら何が返ってきて、本当は何が正しいかが出ます。

変数と型

int   reflect = 47;        /* 整数 */
float distance = 314.2f;   /* 小数。f を付けると float */

気をつけてほしいのは、int どうしの割り算は小数が切り捨てられることです。3 / 2 は 1 になります。小数で計算したいときは、どちらかを (float)3 / 2 のように float にします。

決まった数字は、#define で名前を付けてから使います。

#define WHEEL_RADIUS_MM 50.0f

プログラムの中に 50.0f と直接書くと、あとで何の数字か分からなくなるからです。2026年のプログラムでは、こういう数字を全部 config/parameters.h に集めていました。

条件と繰り返し

if (reflect < 20) {
    /* 黒 */
} else if (reflect > 70) {
    /* 白 */
} else {
    /* その間 */
}

for (int i = 0; i < n; i++) {
    sum += values[i];      /* values[0] から values[n-1] まで */
}

値を2つ返したいとき

関数は return で値を1つしか返せません。2つ返したいときは、書き込む先の場所（ポインタ）を受け取ります。

void find_min_max(const int values[], int n, int *min, int *max)
{
    *min = values[0];      /* min が指している場所に書く */
    ...
}

int lo, hi;
find_min_max(data, 6, &lo, &hi);   /* lo と hi の場所を渡す */

* と & は最初は混乱しますが、&lo が「lo の場所」、関数の中の *min が「その場所の中身」と読めば大丈夫です。

手順

  1. VS Code で ドリル/q01_distance.c を開く
  2. 先頭のコメントを読んで、/* ここに書く */ の所を書く
  3. ターミナルで cd ~/Desktop/ETrobo/docs/後輩育成/新人研修2027/ドリル して、sh check.sh 1 で採点する
  4. × があれば直して、もう一度採点する。全部 ○ になったら次の問題へ

コンパイルできないときは、q01_distance.c:8:5: error: expected ';' のように、ファイル名と行番号が出ます。いちばん上の error だけを見て、その行かひとつ上の行を直してください。下に続くエラーは最初のエラーにつられて出ていることが多いので、1つ直したら採点し直したほうが早いです。

演習

演習6-1　距離から車輪の角度へ（問題1）

走行体を進めたい距離から、車輪（半径50mm）を何度回せばいいかを返す関数を書きます。

ヒント 車輪が1回転（360度）すると、円周（2 × π × 50mm）だけ進む。後ろに進むとき（距離がマイナス）も、同じ式でそのまま角度がマイナスになる。

演習6-2　明るさで場所を分ける（問題2）

カラーセンサの反射光から、黒・線の縁・白のどれを見ているかを返します。

ヒント 「20より小さい」は `reflect < 20` なので、20ちょうどは黒に入らない。20と21で動きが変わる所は、実際のプログラムでもバグが出やすいので、テストにも入れてある。

演習6-3　平均を出す（問題3）

キャリブレーションで読んだ値の平均を返します。

ヒント int どうしの割り算になっていないか確かめる。n が0のときに0で割らないようにする。

演習6-4　いちばん暗い・明るい値を探す（問題4）

配列の中のいちばん小さい値と大きい値を、ポインタで2つ返します。

ヒント 最初の値を「今までで一番小さい（大きい）」として入れておいて、2番目から順に比べていく。
