第3回 ターミナルに慣れる

ETロボコンの開発では、マウスでクリックするより、ターミナルで文字のコマンドを打つ場面のほうがずっと多くなります。走行体のラズパイには画面をつながずに、PCから文字だけで操作するからです。この回は、ずっと使うコマンドを手で打って覚えます。

用意するもの：第2回で準備したPC

説明

行の頭の読み方

VS Code の下に Git Bash を出すと、こんな行が出ています。

taro@PC MINGW64 ~/Desktop/ETrobo (main)
$

taro@PC は誰がどのPCを使っているか、~/Desktop/ETrobo は今いるフォルダ、(main) は Git のブランチの名前（第4回）です。$ は「ここに打ってください」という印です。この資料でも、コマンドの前に $ を書いていますが、$ 自体は打ちません。

ターミナルは、いつもどこか1つのフォルダに「いて」、打ったコマンドはそのフォルダで動きます。今どこにいるかを意識するのが、いちばん大事です。

場所の書き方（パス）

フォルダの場所は / で区切って書きます。これをパスといいます。

~ は自分のホームフォルダ、. は今いるフォルダ、.. は1つ上のフォルダです。docs/後輩育成 のように書くと「今いる場所の中の docs の中の 後輩育成」という意味になります。名前に空白が入っているときは "docs/手がかり/公式 資料" のように " で囲みます。

よく使うコマンド

コマンド すること
pwd 今いるフォルダを表示
ls フォルダの中身を一覧（ls -l で大きさと日時も）
cd フォルダ そのフォルダに移動（cd .. で1つ上、cd だけでホームへ）
cat ファイル ファイルの中身を全部表示
head -n 10 ファイル 最初の10行
tail -n 5 ファイル 最後の5行
less ファイル 1画面ずつ表示（q で終わる、/文字 で探す）
grep 文字 ファイル その文字を含む行だけ表示（-n で行番号、-c で数、-v で含まない行）
mkdir -p フォルダ フォルダを作る
cp 元 先 写す
mv 元 先 動かす、名前を変える
rm ファイル 消す。ゴミ箱には入らず、戻せない

コマンドの出力は、|（パイプ）で次のコマンドに渡せます。grep -v "^\[" ログ | tail -n 15 は「[ で始まらない行のうち、最後の15行」です。> を使うと、出力をファイルに保存できます。

覚えておくキー

Tab は、ファイル名やフォルダ名の続きを補ってくれます。日本語の名前も、最初の1文字を打って Tab を押せば補えます。打ち間違いが減るので、どんどん使ってください。

↑ で前に打ったコマンドが出てきます。Ctrl + C は、動いているものを止めます。何も出ずに止まったように見えるときは、だいたいこれで戻れます。

エラーの読み方

コマンドが失敗すると英語のエラーが出ますが、1行目を読めばだいたい原因が書いてあります。

No such file or directory は「そんなファイルやフォルダは無い」です。名前の打ち間違いか、今いる場所が違います。ls と pwd で確かめます。command not found は「そんなコマンドは無い」で、つづりの間違いが多いです。Permission denied は「権限が無い」です。

grep LAP のようにファイル名を付け忘れると、何も出ずに止まったままになります。キーボードからの入力を待っている状態なので、Ctrl + C で止めます。

取り返しがつかないこと

rm で消したものは戻せません。rm -r フォルダ はフォルダごと消えます。大会の走行ログもこれで消えます。消す前に必ず ls で中身を確かめてください。

> は中身を上書きします。ファイルの最後に足すつもりなら >> です。> と間違えると、前の中身が消えます。

手順

練習用のデータを使います。中身は壊しても大丈夫です（壊したら git restore docs/後輩育成/練習 で元に戻せます）。

  1. VS Code で Git Bash を出して、練習用のフォルダに移動する

    $ cd ~/Desktop/ETrobo/docs/後輩育成/練習/01_ターミナル/練習用データ

    cd ~/De まで打って Tab を押すと続きが出てきます

  2. pwd と ls を打って、今どこにいて、中に何があるかを見る

  3. 演習をやる

演習

演習3-1　場所と中身

  1. メモ/2026年/9月 に入って、中のファイルを一覧にし、0912_試走会.txt の中身を表示してください
  2. 1つ上（2026年）に戻ってください。さらに一気に 練習用データ まで戻ってください
答え 
$ cd メモ/2026年/9月
$ ls
$ cat 0912_試走会.txt
$ cd ..
$ cd ../..

演習3-2　ログを見る

logs の中には、走行体が走ったときの記録（ログ）が3本入っています。

  1. logs/run_20261004_101500.log の最初の10行と、最後の5行を表示してください。最後の行は何ですか
  2. 同じファイルを less で開いて、/LAP で「LAP」を探してください（n で次、q で終わる）
答え `head -n 10 logs/run_20261004_101500.log`、`tail -n 5 logs/run_20261004_101500.log`。最後の行が「競技終了。」なら最後まで走ったということです。途中で切れていたら、そこで止まった（固まった、電源が切れた、Ctrl+C で止めた）ということです。

演習3-3　grep で探す

  1. run_20261004_101500.log から「ボトルの色」を含む行を出してください。ボトルは何色でしたか
  2. 3本のログ全部から「LAP」を含む行を、行番号つきで出してください（ファイル名に logs/*.log と書くと全部が対象になる）
  3. [ で始まる行（1秒ごとの状態の行）以外を出してください。ログが一気に読みやすくなります
答え 
$ grep "ボトルの色" logs/run_20261004_101500.log
$ grep -n "LAP" logs/*.log
$ grep -v "^\[" logs/run_20261004_101500.log
`^` は「行の頭」という意味です。`[` は特別な記号なので、前に `\` を付けて普通の文字として扱います。

演習3-4　作る・写す・消す

  1. メモ/2026年/11月 を作ってください
  2. メモ/2026年/10月/1002_実機.txt を 11月 へ写して、名前を 1105_実機.txt に変えてください
  3. 11月 のフォルダをまるごと消してください。消す前に ls で中身を確かめること
答え 
$ mkdir -p メモ/2026年/11月
$ cp メモ/2026年/10月/1002_実機.txt メモ/2026年/11月/
$ mv メモ/2026年/11月/1002_実機.txt メモ/2026年/11月/1105_実機.txt
$ ls メモ/2026年/11月
$ rm -r メモ/2026年/11月

演習3-5　ログから原因を探す

run_20261003_110000.log は、ガレージの外で止まってしまった走行の記録です（シミュレータで作ったもの）。

  1. 演習3-3の3のやり方で、メッセージだけを読んでください
  2. 「ETラリーの手順を終えました」より後で、予定どおりにいかなかったことを書いている行を2つ探してください
  3. どこから狂ったと思いますか。一言で書いてください

もっと詳しい答えは docs/後輩育成/練習/01_ターミナル/答え.md にあります。自分でやってから見てください。
