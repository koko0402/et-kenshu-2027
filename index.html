ETロボコン 新人研修

ETロボコンに初めて参加する人のための授業です。プログラムを書いたことがなくても、パソコンでコマンドを打ったことがなくても、第1回から順に進めれば、走行体のプログラムを読んで、直して、走らせられるところまで行けるようにしてあります。

各回に、説明、手順、演習があります。説明を読んで、手順どおりに手を動かして、演習で確かめます。演習の答えは、自分でやってから開いてください。分からない言葉は付録の用語集を、コマンドは早見表を引いてください。

授業一覧

第1部　ETロボコンとパソコンの準備
第1回 ETロボコンを知る最初の回は話を聞くのが中心です。
第2回 パソコンの準備プログラムを書いて動かすための道具を、自分のPCに入れます。
第3回 ターミナルに慣れるETロボコンの開発では、マウスでクリックするより、ターミナルで文字のコマンドを打つ場面のほうがずっと多くなります。
第4回 Git で記録するプログラムを直していると、「さっきまで動いていたのに、どこを変えたか分からない」ということが必ず起きます。
第2部　C言語
第5回 はじめてのC言語C言語で、いちばん小さいプログラムを書いて、コンパイルして動かします。
第6回 C言語 変数・条件・繰り返し前の回で書いた小さなプログラムの続きです。
第7回 C言語 関数・構造体・ポインタ関数と構造体を使って、走行体のデータをまとめて扱う練習をします。
第8回 C言語 PID制御と状態機械走行体のプログラムの中心になる2つ、PID制御と状態機械を書きます。
第9回 ファイルの分け方と makeここまでは1つのファイルにプログラムを書いてきました。
第3部　走らせる
第10回 ライントレースのしくみ走行体は、床の黒い線の縁をカラーセンサで見ながら走ります。
第11回 シミュレータ（1）ライントレース前の回は文字だけのシミュレータでしたが、この回からは、エントリークラスと同じ点数の付け方をする練習用のシミュレータで、コースを1周させます。
第12回 シミュレータ（2）ブロックを運んでガレージで止まる前回のライントレースに状態機械を足して、LAPのあとのブロック運びとガレージ停止までを作ります。
第4部　モデル
第13回 モデル図とはETロボコンでは、プログラムを走らせた点数と同じくらい、設計図（モデル）の審査が大事です。
第14回 状態機械図を描く第12回で作ったシミュレータのプログラムを、状態機械図にします。
第15回 審査で見られるモデルここまでの図は、主に「どう作るか」の図でした。
第5部　実機と本物のプログラム
第16回 ラズパイをつなぐ（実習）ここからは実機です。
第17回 走行体のプログラムを動かす（実習）前の回でラズパイに送った、2026年の本物の走行体のプログラムを動かします。
第18回 ログを読む・Python で集計する走行体は、走りながら「何を見て、どう判断したか」を1行ずつログに書いています。
第19回 本物のプログラムを仮想コースで走らせる第11回・第12回のシミュレータは、練習用に自分で書いたプログラムを走らせるものでした。
第20回 機能を足すときの手順ここまでで、走行体のプログラムを読んで、動かして、ログを読めるようになりました。
第6部　仕上げ
第21回 AIとの付き合い方2026年のチームは、プログラムや設計書、資料の多くを、生成AI（VS Code の中で動く Claude Code）と一緒に作りました。
第22回 まとめの発表1か月の最後に、自分の作ったものを先輩の前で5分くらいで説明してもらいます。

進め方

全部で22回あります。週に3〜4回のペースで、だいたい2か月です。第1部から第3部まではPCだけでできます。実機（走行体）を使うのは第5部からで、先輩と一緒にやります。

ドリルやシミュレータは、授業の時間だけで終わらなければ次の回までにやってきてください。分からないところで10分考えて進まなかったら、先輩に聞いてください。聞くときは「何をしたら、何が出て、何を期待していたか」を言うと、すぐに答えられます。

最後の第22回では、自分の作ったものを5分くらいで説明してもらいます。うまく走ったかどうかより、なぜそう作ったのかを聞きます。
