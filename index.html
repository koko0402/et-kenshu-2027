ETロボコン 新人研修 2027

2026年11月に入ってくれた人向けの研修です。来年のETロボコンに向けて、1か月で11回の授業をします。

大会のしくみを知るところから始めて、C言語で走行体の計算を書き、練習用のシミュレータで自分のプログラムを走らせて、状態機械図を描き、最後にラズパイを実際につなぎます。各回に説明と手順と演習があります。演習の答えは、自分でやってから開いてください。

授業一覧

回内容
第1回 ETロボコンを知るこの回は講義が中心です。
第2回 開発環境とターミナル自分のPCで、Cのプログラムを書いてコンパイルして動かせるようにします。
第3回 C言語（1）変数・条件・繰り返しC言語の基本を、走行体で使う計算を題材に練習します。
第4回 C言語（2）関数・構造体関数と構造体を使って、走行体のデータをまとめて扱う練習をします。
第5回 C言語（3）PID制御と状態機械走行体のプログラムの中心になる2つ、PID制御と状態機械を書きます。
第6回 シミュレータ（1）ライントレースエントリークラスと同じ点数の付け方をする練習用のシミュレータで、自分のプログラムを走らせます。
第7回 シミュレータ（2）ブロックを運んでガレージで止まる前回のライントレースに状態機械を足して、LAPのあとのブロック運びとガレージ停止までを作ります。
第8回 状態機械図を描く前回作った走行体のプログラムを、モデル（状態機械図）にします。
第9回 ラズパイをつなぐ（実習）ここからは実機です。
第10回 AIとの付き合い方2026年のチームは、プログラムや設計書、資料の多くを、生成AI（VS Code の中で動く Claude Code）と一緒に作りました。
第11回 まとめの発表1か月の最後に、自分の作ったものを先輩の前で5分くらいで説明してもらいます。

進め方

1週目に第1回と第2回、2週目に第3回から第6回、3週目に第7回と第8回、4週目に第9回から第11回、くらいのペースを考えています。ドリルやシミュレータは、授業の時間だけで終わらなければ次の回までにやってきてください。

第11回では、自分の作ったものを5分くらいで説明してもらいます。うまく走ったかどうかより、なぜそう作ったのかを聞きます。

準備

ドリルとシミュレータは、PCで gcc・mingw32-make・Git が動けばできます（入れ方は第2回）。ラズパイと実機を使うのは第9回だけです。
